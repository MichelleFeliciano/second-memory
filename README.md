# Second Memory

A personal, local-first organizer — books, recipes, medications, diagnoses, a to-do
list, a shopping list, notes, a household budget/bills tracker, resume & portfolio
links, and coursework, all in one place. (The authoritative current list of sections
lives in the `TABS` constant in `app.js`.)

## Use it now

The app is already live at **https://sagebrushsites.com/second-memory/** — that's the
normal way to use it day to day. Nothing to install; it works in any modern browser, on
any device, and can be added to your phone's home screen like an app (it's a PWA).

All of your data is stored in that browser's `localStorage`, on that device only.
Nothing is sent anywhere over the network unless you deliberately set up syncing between
devices, described below.

## Syncing between devices (optional)

By default, each device you use keeps its own separate copy of your data. If you want
your phone, laptop, etc. to share the same data, you can run a small sync server on one
computer you own and point each device at it.

1. On the computer that will act as the sync server, run:

   ```
   python sync_server.py
   ```

   The first time it runs, it generates a self-signed HTTPS certificate and a random
   passphrase, which it prints to the terminal and also saves to `.sync_secret` in this
   folder. Keep that passphrase handy — you'll enter it on each device.

2. On each device, open the app (at the sagebrushsites.com URL above), find the sync
   setup form, and enter that computer's server address and the passphrase.

Syncing only happens while that computer's `sync_server.py` process is actually running.
The app itself always loads and always shows whatever is already saved on that device
regardless of whether the sync server is up — it's hosted separately, on GitHub Pages,
and doesn't depend on your computer being on.

### Reaching the sync server from outside your home network

Sync works over your home LAN automatically. To reach it from other networks (e.g. your
phone on cellular data, or a laptop away from home), use
[Tailscale](https://tailscale.com/):

1. Install Tailscale on the computer running `sync_server.py` and on each device you
   want to sync.
2. Sign into the same Tailscale account/network on all of them.
3. Restart `sync_server.py`. It automatically detects Tailscale and includes its IP
   address and MagicDNS hostname in the HTTPS certificate, so the server is reachable
   from anywhere Tailscale connects — not just your home network — without exposing
   anything to the public internet.

### One-time step per device/browser: trust the server's certificate

Because the sync server uses a self-signed certificate, browsers will refuse the
connection until you've told them to trust it. Now that the app page and the sync server
live on different origins, this requires a separate, explicit step:

On each device, before sync will work, visit the sync server's HTTPS address directly in
that browser once — e.g. `https://yourcomputer.tailXXXXXX.ts.net:8443/` (or the LAN
IP/port printed when `sync_server.py` starts) — and click through the "connection isn't
private" warning to accept the certificate. Do this once per browser per device. If you
skip this step, the browser will silently block the app's sync requests to that server
rather than showing a clear error.

## Files

- `index.html`, `style.css`, `app.js` — the app
- `manifest.json`, `icons/` — installable PWA assets
- `sync_server.py` — optional local HTTPS sync server

`cert.pem`, `key.pem`, `.sync_secret`, and `sync_data.json` are generated by
`sync_server.py` and are specific to the machine it runs on. They're git-ignored — never
commit them.
